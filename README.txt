Deployment
This is a static website. Upload the entire folder to Cloudflare Pages, Netlify, GitHub Pages or any conventional static web host. Do not upload only index.html; the assets and CSS/JS folders must stay together.

Custom domain
After deployment, point sourcingbridgeco.com to the hosting provider. Preserve the existing email DNS records (MX, SPF, DKIM and DMARC) when changing website DNS.

No analytics or non-essential cookies are included in this build.
